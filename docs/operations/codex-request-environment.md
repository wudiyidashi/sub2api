# Codex 账号出口环境

管理员在账号编辑页选择代理后，可以在“请求出口环境”中查看实际出口 IP、国家、地区、城市、IANA 时区及当地日期，或点击“重新检查”。预览不会改变账号的代理绑定。保存账号后自动预热；首次转发时也会检查。

服务通过账号选择的代理访问 GeoJS 的 HTTPS 地域查询服务，失败时尝试 ipwho.is；无代理的账号使用服务器实际出口。查询只携带地域查询请求，不发送账号令牌或业务正文。第三方查询服务会看到出口 IP。探测使用实际出站连接，不以代理服务器主机地址或国家代码猜测时区。

HTTP、SSE 与 WebSocket 的原生和增强管理方式均应用相同策略：

- 已识别的 Codex 环境上下文和客户端时间上下文，对齐时区、当地日期，以及其中已有的时间、UTC 偏移、IP、国家、地区和城市字段。按 IANA 时区计算日期及夏令时。
- 搜索工具的地域与时区对齐到所选出口。
- 操作系统、工作目录、文件路径、语言偏好和普通业务文本保留实际值。IP 不能确定这些信息。

地域快照有效期为 15 分钟，按出口共享并持久化。代理地址或认证信息变化会使旧快照失效；手动重新检查会跳过快照。探测失败时暂停对应 Codex 请求并提示检查代理或查询服务连通性，不使用过期地域，也不降级为直连。失败后短暂退避 30 秒，管理员仍可手动重试。

WebSocket 会话固定使用连接建立时的地域快照；新快照的出口 IP 或地域改变时，会隔离连接池复用。已有连接不会在会话中途切换时区。

**使用固定或粘性代理出口。** 如果同一代理地址在不同连接、目标网站或 IP 协议族之间分配不同出口，单独的地域查询不能证明后续到 ChatGPT 的连接使用相同 IP。15 分钟缓存也不能保证自动发现期间发生的 IP 轮换。需要代理提供商保证出口稳定；网络出口改变后可手动重新检查。

本功能不需要开启完整请求／响应内容审计，生产环境可以继续关闭完整内容记录。
